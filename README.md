# RápidoNF - MVP

Solução desenvolvida pela **Luyon Automações®** para a clínica **Casa Psico Psicologia Clínica Ltda**.

## Objetivo
Otimizar o fluxo operacional de emissão de NFS-e, reduzindo a sobrecarga burocrática e garantindo agilidade (< 60s), segurança e conformidade com o ODS 8.

## Stack Tecnológica
- **Backend:** Python 3 (Flask 3.0)
- **Base de Dados:** SQLite
- **Frontend:** HTML5, Jinja2, Bootstrap 5
- **Testes & CI:** Pytest e GitHub Actions
