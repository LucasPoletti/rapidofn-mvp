# RápidoNF - MVP

Solução desenvolvida pela **Luyon Automações®** para a clínica **Casa Psico Psicologia Clínica Ltda**.

## Objetivo
Otimizar o fluxo de emissão de Notas Fiscais de Serviço eletrónicas (NFS-e), reduzindo a sobrecarga operacional em ambiente clínico para emissões ágeis (< 60 segundos), em conformidade com o ODS 8 (Meta 8.2).

## Stack Tecnológica
- **Backend:** Python 3 (Flask 3.0)
- **Base de Dados:** SQLite3
- **Frontend:** HTML5, Jinja2, Bootstrap 5
- **Testes Automatizados:** Pytest
